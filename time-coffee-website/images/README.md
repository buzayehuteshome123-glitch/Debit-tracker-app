# Photos

Drop your own photos here with these exact names and the website uses them
automatically. Until a file exists, a stock photo is shown in its place.

| File             | Where it appears                     |
| ---------------- | ------------------------------------ |
| `hero.jpg`       | Big image at the top of the page     |
| `burger.jpg`     | Burgers card + Classic Burger        |
| `pizza.jpg`      | Pizza card + Loaded Pizza            |
| `juice.jpg`      | Fresh Juice card + Fresh Mixed Juice |
| `fries.jpg`      | Sides card + Crispy Fries            |
| `combo.jpg`      | Special Combo banner                 |
| `restaurant.jpg` | Visit Us section                     |
