# Time Coffee — Restaurant Website

A static one-page website (HTML + CSS + a little JavaScript). No build step.

- **Preview:** open `index.html` in a browser.
- **Publish:** upload this folder to any static host (Netlify, Vercel, GitHub Pages, cPanel…).
- **Orders:** every "Order Now" / "Get the Combo" button opens WhatsApp with the item
  pre-filled. Change the number in `script.js` (`WHATSAPP_NUMBER`).
- **Photos:** see `images/README.md`.
- **Prices, hours, address:** edit the text directly in `index.html`.
